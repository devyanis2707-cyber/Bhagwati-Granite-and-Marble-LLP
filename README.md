# Bhagwati Granite and Marble LLP - Premium Luxury Website

## 🌟 Project Overview

A premium, cinematic, ultra-modern luxury website for Bhagwati Granite and Marble LLP - a leading supplier of premium granite, marble, and natural stones. Built with HTML5, CSS3, Bootstrap 5, JavaScript (ES6), and GSAP animations.

### ✨ Features

- **Responsive Design**: Perfectly optimized for mobile, tablet, laptop, desktop, and 4K screens
- **Premium Animations**: GSAP, ScrollReveal, AOS for cinematic effects
- **Dark Luxury Theme**: Black, white, grey marble tones with gold accents
- **Glassmorphism**: Modern glass-effect cards and components
- **Advanced UI Effects**:
  - Sticky navbar with blur effect
  - Dynamic navbar color change on scroll
  - Mouse-follow glow effects
  - Cursor trail effect
  - Floating gradient blobs
  - Smooth reveal animations
  - Animated text masking
  - Scroll progress indicator
  - Back-to-top button
  - Luxury loading screen

### 📱 Responsive Across All Devices

- Mobile (320px+)
- Tablet (768px+)
- Laptop (1024px+)
- Desktop (1440px+)
- Ultra-wide/4K (2560px+)

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code recommended)
- Live Server extension (for development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/devyanis2707-cyber/Bhagwati-Granite-and-Marble-LLP.git
   cd Bhagwati-Granite-and-Marble-LLP
   ```

2. **Setup Assets**
   - Place your logo in `assets/logo.png`
   - Place owner photo in `assets/owner.jpg`
   - Add product images to `assets/images/`

3. **Run with Live Server**
   - Open `index.html` with Live Server
   - Or use Python: `python -m http.server 8000`
   - Visit: `http://localhost:8000`

### Development

```bash
# No build process required - pure HTML/CSS/JS
# Edit files directly and refresh browser
# All animations work instantly
```

## 🐛 Troubleshooting

### Animations not working
- Ensure GSAP is loaded from CDN
- Check browser console for errors
- Disable ad-blocker

### Images not loading
- Check file paths
- Verify image files exist
- Use absolute paths if needed

### Responsive issues
- Clear browser cache
- Check viewport meta tag
- Test in incognito mode
